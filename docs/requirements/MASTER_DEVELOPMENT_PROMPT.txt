11. CERTIFICATE GENERATION IMPLEMENTATION

Build the certificate system with:

ASP.NET Core + PostgreSQL + QuestPDF + QR verification.

Workflow:

1. Student completes programme requirements.
2. Eligibility engine evaluates the applicable programme rules.
3. Examination Cell verifies final academic results.
4. Authorized officer approves the certificate.
5. Background worker generates the PDF.
6. Certificate is assigned a unique registry number.
7. PDF is digitally signed where authorized.
8. Document is stored securely.
9. Student receives notification.
10. Student or alumnus downloads the document.
11. External verifier checks the certificate through a secure verification page.

Store:

- Certificate ID
- Institution ID
- Student ID
- Certificate type
- Template version
- Issue date
- Approval history
- Document hash
- Signature status
- Storage reference
- Verification status
- Reissue history

Do not expose private student records on the public verification page.
