# Timetable and attendance increment — 2026-10-14

Implemented behavior: administrator classroom/subject configuration; dated period allocation to room, faculty and programme/session/semester/section; frozen roster at booking; cancellation with audit and retained history; assigned faculty attendance; complete-roster validation; locked submission and replay rejection; correction request and separate administrator approval/rejection; scoped subject attendance reports. Faculty profiles now support versioned edits and reasoned archive; pending classes prevent faculty archiving.

Database migration: TimetableAttendance adds Classrooms, Subjects, ClassSessions, ClassRosters, AttendanceRecords, AttendanceCorrections and optional faculty-account links. Composite FKs preserve institution boundaries and subject/cohort consistency. PostgreSQL btree_gist exclusion constraints reject room, faculty and class-group overlaps, including simultaneous bookings; adjacent periods use [start,end) intervals. Migration installation needs a database role authorized to install the trusted btree_gist extension. References: https://www.postgresql.org/docs/17/rangetypes.html and https://www.postgresql.org/docs/17/btree-gist.html.
